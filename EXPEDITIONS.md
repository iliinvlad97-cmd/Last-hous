# v0.9.6 — Expeditions, Stage 2

Карта и подготовка остаются внутри `GameView`. `CityMapController` обрабатывает
выбор точки, состав отряда и касания. `ExpeditionPreparationRenderer` и
`ExpeditionRenderer` только отображают данные; отправка проходит через
`GameController.expeditionController`.

## Состояние и время

`GameState.cityLocations` содержит прежние шесть `MapLocation`; UI и контроллер
используют одни объекты. Старая `Location` оставлена для совместимости её save slots.
Новая модель локаций не создавалась.

`Expedition` хранит ID цели, неизменяемый список ID участников, игровую минуту
отправления, длительность, прошедшие игровые минуты и состояние. Коллекция
экспедиций позволяет позже поддержать несколько отрядов; сейчас
`ExpeditionConfig.MAX_ACTIVE = 1`, состав — от 1 до 3 жителей.

`ExpeditionConfig` задаёт путь в одну сторону: 45 / 90 / 150 игровых минут
для близкого / среднего / дальнего расстояния. Оценка пути обратно показывается
в подготовке, но возвращение на этом этапе не запускается.

Прогресс обновляется только из существующего `advanceMinute()` и существующего
односекундного `GameView.tick`. Пауза, события, game over и скорости ×1/×2/×4
действуют через этот же цикл. Переход через полночь сохраняет прошедшие минуты.
Маршрут восстанавливается из нормализованных координат карты. Сглаживание
маркера через перерисовку не меняет игровое время и останавливается при паузе.

При прибытии состояние становится `AT_LOCATION` и сохраняется. Отряд остаётся
на цели, продолжает занимать слот активной экспедиции и не получает награды.
Исследование, возвращение, добыча, случайные события и ранения экспедиций
не реализованы. Условие допуска: существующий живой житель со здоровьем выше
нуля, не участвующий в экспедиции. Новый порог усталости не вводился.

## Жители и сохранения

Участники сохраняются в существующем списке `people`, получают
`Resident.Status.ON_EXPEDITION` и совместимое занятие `Экспедиция`.
`homeRoomFor()` возвращает для них −1; исходный `ResidentRenderer` не рисует
их в убежище. Контроллер исключает их из работы, автоматического назначения,
домашнего лечения и воздействия событий на жителей. Работа остальных жителей
и численные коэффициенты производства сохранены. Ручное назначение работы
и отдыха участникам заблокировано; просмотр в «Жителях» доступен.

Пространство `save_v02` и все старые ключи сохранены. Добавлены:

- `p{index}_id` — стабильный ID жителя; у старого сохранения default `legacy-{index}`.
- `exp2_schema`, `exp2_count` — формат и число записей.
- `exp2_{index}_location`, `participants`, `state`, `departure`, `duration`, `elapsed`.

Записи экспедиций и жители записываются одним `SharedPreferences.Editor.apply()`.
Движение сохраняется после каждой игровой минуты, а отправка — немедленно.
При загрузке проверяются цель, ID участников, повторения, длительность и состояние;
участие восстанавливается до отрисовки комнат. Повторная загрузка очищает коллекцию
экспедиций перед восстановлением.

Старая активная экспедиция из `expPerson` / `expLoc` / `expRemain` мигрирует
в новый отряд по соответствующему слоту цели с оставшимся временем пути.
Старые поля после миграции записываются с неактивными значениями; второй таймер
и прежняя автоматическая награда не запускаются. Некорректная запись не создаёт
отряд и не возвращает жителей в комнаты; в журнал добавляется сообщение.

## Проверка

В настроенной Android/JDK 21 среде:

```bash
python3 tools/expedition_regression.py
python3 tools/city_map_regression.py
python3 tools/grounding_regression.py
gradle --no-daemon --max-workers=2 assembleDebug lintDebug
```

JVM-проверки используют Android doubles и настоящий код игры. Они проверяют
отправку, ошибки без частичных изменений, выбор/страницы, таймер, паузу/скорости,
маршрут, навигацию, AI, прибытие, новые и старые сохранения. Grounding-проверки
также сравнивают неизменённую симуляцию со старой базой; прежние автоматические
экспедиции с наградами заменены отдельными проверками Stage 2.

Это не проверка установки или отрисовки на Android-устройстве. Перед Stage 3
нужно проверить APK на реальном устройстве: отправку 1 и 3 жителей, паузу/скорости,
навигацию, перезапуск в пути и после прибытия, работу оставшихся жителей.
Подпись APK и автоматическая CI-схема versionCode сохранены.
