# Последний дом — Android prototype

Мобильная игра на Java без внешних игровых библиотек. Вертикальный режим.

## Что уже есть
- главный экран убежища с рисуемой Canvas-графикой;
- 5 жителей с ролями;
- еда, вода, электричество, материалы;
- назначение жителей на работу;
- события с выбором решения;
- последствия и риск смерти;
- улучшение здания;
- журнал событий;
- автосохранение прогресса через SharedPreferences;
- экран поражения и новая игра.

## Открытие
Откройте папку `LastHouse` в Android Studio. Проект использует Android Gradle Plugin 9.4.0 / Gradle 9.6 и compileSdk 37.

## Следующий этап
Добавить настоящие PNG/спрайты, звук, больше комнат, дерево улучшений, сюжетные ветки и балансирование экономики.

## Быстрая сборка APK через GitHub

В проект добавлен `.github/workflows/build-apk.yml`. Он автоматически устанавливает Android SDK и Gradle 9.6 на GitHub Actions и публикует `app-debug.apk` как artifact.
